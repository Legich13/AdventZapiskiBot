# Правила проекта

Изучите [архитектуру](ARCHITECTURE.md) и [порядок работы с планом](plan/README.md). Маршруты и контроллеры адаптируют запросы. Авторизация, нормализация входа, операции с базой и рендеринг имеют отдельные проверяемые границы. Для изменений в Laravel прочтите [правила backend](backend/AGENTS.md) и [профиль модулей](docs/backend/ARCHITECTURE.md). Сверяйте применимые ARCH-ID в корневой архитектуре. При изменении API обновите экспорт Scramble и связанный бизнес-сценарий. Для Eloquent-моделей документируйте назначение, поля, связи и инварианты на русском.

Пишите поведенческие тесты Pest на русском. Перед реализацией получите диагностируемое падение целевого теста, затем пройдите его той же командой. Запускайте проверки в контейнерной среде через цели Make.

Для библиотеки, фреймворка, SDK, API, CLI или облачного сервиса извлеките актуальную документацию через Context7 MCP. Сначала вызовите resolve-library-id, если нет точного ID, затем query-docs по выбранному ID и вопросу пользователя. Для общих вопросов программирования и рефакторинга достаточно исходного кода.
