# Подготовить и опубликовать календарь

## Брифинг

Автор создаёт личный календарь для себя или обладателя указанного Telegram-ника.

## Для пользователя

Запустите бота командой `/start` и нажмите «Создать календарь». Если у вас уже есть календари, откройте «Мои календари» и выберите действие в разделе «Я создаю». Mini App откроет редактор с Telegram-авторизацией. Выберите адресата и месяц. У каждого отмеченного дня есть отдельное поле для записки.

## Основной сценарий

1. Выберите даты.
2. Введите текст для каждой даты и сохраните черновик.
3. Нажмите «Опубликовать».
4. Получатель запускает /start. Бот привязывает календарь к его Telegram ID и отправляет открытку. Если вручаются сразу несколько календарей, одна открытка ведёт к списку.

## Альтернативные сценарии

Подарок себе доступен и без username. Черновик с незаполненной датой можно продолжить позже. У календаря, опубликованного по нику, автор может исправить адрес до вручения.

При публикации себе с 10:00 МСК уведомление о сегодняшнем подарке поступает в очередь после сохранения. Для другого человека рассылка начинается после подтверждённой доставки открытки по /start. Повторная команда сохраняет одну доставку за день.

Если при публикации уже задан числовой Telegram ID, адресат закреплён сразу. При первом личном /start после публикации бот вручает календарь владельцу этого ID, в том числе при смене или удалении ника. Автор может редактировать будущие записки.

## Бизнес-правила

У получателя один опубликованный календарь на месяц. Будущие тексты можно редактировать. Для совместимости с ранее отправленными карточками сохраняется лимит записки в 1024 байта вместе с сериализованным ответом.

## Чеклист тестирования

Проверить приветствие без полученных календарей, открытие редактора встроенной кнопкой с Telegram-авторизацией, месяц на 28, 29 и 31 день, пустое поле, повторную публикацию, два одновременных запроса и смену ника.

## Зона риска

Без первого запуска бот располагает только ником. Календарь получит владелец имени на момент вручения.

## Связанные API

miniAppSession, saveCalendarDraft, updateCalendar, publishCalendar, receiveTelegramUpdate. [Контракт](../backend/API_CONTRACT.md).

## Логи и следы

Статус календаря и времена публикации и вручения показаны в админке. Текст подарка доступен автору через редактор.

## Ошибки

Неправильные даты или слишком длинный текст отмечаются в форме. Если месяц занят, содержимое черновика сохраняется для исправления.

## Готово, когда

Автор видит публикацию. Получатель после /start открывает календарь в Mini App по кнопке на открытке. Следующая команда /start даёт доступ к своим календарям.
