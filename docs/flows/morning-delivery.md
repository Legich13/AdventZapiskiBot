# Получить утреннюю карточку

## Брифинг

В 10:00 МСК начинается рассылка отдельного сообщения на сегодняшнюю дату.

## Для пользователя

Если подарок уже прочитан, карточка предложит «Посмотреть ещё раз». В дни без подарка сообщения нет.

## Основной сценарий

1. Планировщик выбирает получателей сегодняшнего подарка.
2. PostgreSQL резервирует пару получатель–дата.
3. Воркер отправляет новый виджет.
4. По нажатию открывается назначенная записка.

## Альтернативные сценарии

При публикации календаря себе или вручении через /start с 10:00 МСК сегодняшняя карточка сразу ставится в очередь после коммита. Получатель не ждёт следующего назначенного дня или минутного планировщика. Явный ответ Telegram 429 переносит попытку с учётом retry_after.

## Бизнес-правила

С 10:00 МСК учитываются все уже вручённые календари с подарком на текущую московскую дату. Черновик, невручённый календарь и будущее время вручения исключены. На получателя и дату создаётся одна доставка; повтор публикации, /start и планировщика не добавляет вторую карточку. Факт открытия утром не исключает участника. Известная ошибка и неизвестный результат сохраняются раздельно. Прошлые дни не досылаются.

## Чеклист тестирования

Сравнить 09:59, 10:00 и позднюю публикацию себе или /start, открытый и закрытый подарок, получателя без даты, откат транзакции, повторные команды, пересечение с планировщиком и виртуальное время мастерской. Проверить потерю сети и ограничение 429.

## Зона риска

Повтор запроса с неизвестным исходом может дублировать уведомление. После окончания дня устаревшее задание прекращается.

## Связанные API

Планировщик действует внутри приложения. Нажатия обрабатывает receiveTelegramUpdate. [Открытие записки](open-gift.md).

## Логи и следы

morning_deliveries содержит дату и статус. widget_messages хранит связь с подтверждённым сообщением. Факт прочтения смотрите отдельно в gift_days.

## Ошибки

Блокировка бота завершает отправку. При неоднозначном сетевом результате сервис не отправляет второе сообщение автоматически.

## Готово, когда

В локальном чате видна одна новая карточка за день с кнопкой, соответствующей состоянию открытия.
