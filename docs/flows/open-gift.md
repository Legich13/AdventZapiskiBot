# Открыть и перечитать записку

## Брифинг

Полный календарь и утренняя карточка дают доступ к одной записке дня.

## Для пользователя

При появлении карточка показывает «Обновляем календарь…». Когда кнопки станут доступны, нажмите дату или кнопку утреннего подарка. Закрыть записку можно из того же сообщения.

## Основной сценарий

1. Telegram передаёт серверу ID пользователя и сообщения.
2. Бот находит исходный календарь и проверяет московскую дату.
3. Первое открытие отмечается в базе, виджет показывает авторский текст.

## Альтернативные сценарии

При повторном открытии появляется прежняя записка. Старое сообщение продолжает указывать на свой календарь и день.

## Бизнес-правила

Дни доступны с 00:00 Europe/Moscow. Прогресс увеличивается один раз. Сервер заново проверяет получателя и дату при каждом запросе.

## Чеклист тестирования

Проверить секунду перед полуночью, следующую минуту, повторный тап, чужое сообщение и прошлый месяц.

## Зона риска

Будущие записки должны оставаться на сервере. В исходный HTML попадают даты и состояния.

## Связанные API

receiveTelegramUpdate. Персональный ответ передаётся через answerWidgetQuery. [Telegram](../backend/telegram.md).

## Логи и следы

gift_days.opened_at фиксирует первое открытие. Успешная доставка сообщения учитывается отдельно.

## Ошибки

Если обновление состояния завершилось ошибкой, кнопки снова доступны. Нажатие запрашивает подарок у бота, который проверяет актуальную дату и право получателя. При потере связи во время самого открытия можно нажать ещё раз.

## Готово, когда

Первый тап показывает записку, повторный возвращает её с сохранённым счётчиком.
