# Среда и доставка

Docker Compose запускает Laravel, PostgreSQL 18.6, планировщик и работника очереди. Службы используют один каталог приложения и одну основную базу. PostgreSQL использует отдельный именованный том для основной версии 18. Базы тестов отделены от основной. Версии зависимостей зафиксированы в Composer lock, образы — в Dockerfile и compose.yaml.

Планировщик проверяет текущую московскую дату и время. С 10:00 он подбирает уже вручённые календари с сегодняшним подарком, включая вручённые после 10:00. Публикация себе и новое вручение через /start вызывают тот же отбор для конкретного получателя сразу: резерв сохраняется в транзакции, задание очереди создаётся после коммита. Повторные проходы планировщика подхватывают пропущенный запуск и возобновляют ожидающие задания. Воркеры используют общее ограничение частоты. При неизвестном исходе сеть могла принять запрос, поэтому запись остаётся на проверку. Для диагностики сравните состояние отправки, время первой попытки и отдельное время открытия.

В production нужны HTTPS, ключ приложения, токен бота, секрет webhook, база и оба фоновых процесса. Режим local включает тестовые роли и часы; доступ к /dev проверяется также при кешированных маршрутах. Секреты задаются через переменные окружения.

В локальном PHP-образе Node.js исполняет сгенерированный JavaScript обеих карточек при запуске Pest. Тесты моделируют задержанный ответ Telegram и ограничение одного запроса в полёте. Рендеринг и отправку карточек выполняет Laravel.
