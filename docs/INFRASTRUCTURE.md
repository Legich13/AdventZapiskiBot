# Среда и доставка

Docker Compose запускает Laravel, PostgreSQL 18.6, планировщик и работника очереди. Службы используют один каталог приложения и одну основную базу. PostgreSQL использует отдельный именованный том для основной версии 18. Базы тестов отделены от основной. Версии зависимостей зафиксированы в Composer lock, образы — в Dockerfile и compose.yaml.

Планировщик проверяет текущую московскую дату и время. С 10:00 он подбирает вручённые календари с сегодняшним подарком. При вручении через /start готовность текущей доставки наступает после подтверждения открытки. При публикации себе отбор запускается после коммита. Повторные проходы планировщика подхватывают пропущенный запуск и возобновляют ожидающие задания. Воркеры используют общее ограничение частоты. При неизвестном исходе сеть могла принять запрос, поэтому запись остаётся на проверку. Для диагностики сравните состояние отправки, время первой попытки и отдельное время открытия.

В production нужны HTTPS, ключ приложения, токен бота, секрет webhook, база и оба фоновых процесса. Режим local включает тестовые роли и часы; доступ к /dev проверяется также при кешированных маршрутах. Секреты задаются через переменные окружения.

Для HTTPS в `APP_URL` сессионная cookie по умолчанию получает `Secure`, `HttpOnly`, `SameSite=None` и `Partitioned`. Это позволяет Telegram Web передавать сессию во вложенной странице. При локальном HTTP используется `SameSite=Lax`. [Документация браузеров](https://developer.mozilla.org/en-US/docs/Web/Privacy/Guides/Third-party_cookies/Partitioned_cookies)

На новом стенде установите приложение вместе с файлом обложки и выполните штатные миграции. После этого запустите HTTP-приложение, планировщик и воркеры. В локальном окружении эти шаги выполняет `make setup`.

В локальном PHP-образе Node.js исполняет сгенерированный JavaScript обеих карточек при запуске Pest. Тесты моделируют задержанный ответ Telegram и ограничение одного запроса в полёте. Новые сообщения отправляет Laravel. Локальная мастерская повторяет их тип и ведёт по тем же маршрутам Mini App.
