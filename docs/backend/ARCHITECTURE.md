# Модули Laravel

Нормативное направление зависимостей задаёт [корневая архитектура](../../ARCHITECTURE.md). HTTP, Filament, команды Artisan и очередь используют общие прикладные операции.

| Модуль | Вход | Владелец правил |
|---|---|---|
| Calendar | Mini App, подтверждённый пользователь бота | Actions сохраняют черновик, публикуют его, привязывают получателя и открывают день. Repository фиксирует изменения и блокировки в PostgreSQL. Services формируют данные редактора. |
| Telegram | Webhook, планировщик, SendMorningGift | Обработчик преобразует update в типизированные данные. Виджеты вызывают ту же операцию открытия. Адаптер Nutgram отвечает Telegram, репозитории сохраняют адрес сообщения и ход доставки. |
| Studio | Маршруты /dev в локальном окружении | Сессия выбирает тестового участника и время. Управление переходит к рабочим операциям Calendar и Telegram. |
| Admin | Аутентифицированный сотрудник Filament | Read service получает ограниченные выборки людей, календарей и доставок. Панель отображает эти данные и документацию. |

Стабильные формы проходят между слоями через final readonly DTO. HTTP Resource перечисляет поля ответа. Eloquent-модели используются внутри persistence. Блокировка открытия защищает первую отметку от двух параллельных нажатий. PostgreSQL удерживает идентичность получателя при смене ника.
