# Модули Laravel

Нормативное направление зависимостей задаёт [корневая архитектура](../../ARCHITECTURE.md). HTTP, Filament, команды Artisan и очередь используют общие прикладные операции.

| Модуль | Вход | Владелец правил |
|---|---|---|
| Calendar | Mini App, подтверждённый пользователь бота | Actions сохраняют черновик, публикуют его, привязывают получателя и открывают день. Repository фиксирует изменения и блокировки в PostgreSQL. Сервисы раздельно готовят авторский редактор и экран получателя. Модель месяца для получателя содержит даты и состояние открытия. Текст одной записки выдаёт OpenGiftAction. |
| Telegram | Webhook, планировщик, SendMorningGift | Обработчик преобразует update в типизированные данные. Адаптер Nutgram отправляет фото при вручении и текстовые сообщения с кнопками Mini App. Ранее доставленные виджеты вызывают ту же операцию открытия. Репозитории сохраняют тип сообщения, адрес кнопки и ход доставки. |
| Studio | Маршруты /dev в локальном окружении | Сессия выбирает тестового участника и время. Мастерская вызывает рабочие операции Calendar и Telegram и показывает записанные сообщения с переходами в Mini App. |
| Admin | Аутентифицированный сотрудник Filament | Read service получает ограниченные выборки людей, календарей и доставок. Панель отображает эти данные и документацию. |

Стабильные формы проходят между слоями через final readonly DTO. HTTP Resource перечисляет поля ответа. Eloquent-модели используются внутри persistence. Блокировка открытия защищает первую отметку от двух параллельных нажатий. PostgreSQL удерживает идентичность получателя при смене ника.
