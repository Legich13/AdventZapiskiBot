# HTTP и Telegram

Главная Mini App открывается по GET /app. Кнопка создания ведёт на /app?create=1, старые авторские ссылки /app?calendar=ID открывают редактор. Получатель видит месяц по /app/received/{calendar} и коробку за выбранный день по /app/received/{calendar}/{date}. Дата задаётся в формате ГГГГ-ММ-ДД. При запуске клиент подтверждает личность Telegram и загружает исходный адрес. Запись идёт через защищённые сессионные маршруты того же origin.

Первый переход получает общую страницу входа. `POST /app/session` проверяет подпись и срок действия `initData` от Telegram. Клиент отправляет SHA-256 исходной строки в заголовке `X-Mini-App-Launch` при загрузке личных страниц и изменении данных. Сервер сверяет значение с текущей сессией. Если в соседней вкладке открыт другой Telegram-аккаунт, старая форма получает 401. Для записи клиент также передаёт `X-CSRF-TOKEN`.

| HTTP | operationId | Назначение |
|---|---|---|
| POST /app/session | miniAppSession | Обмен подписанного Telegram initData на сессию. |
| POST /app/calendars | saveCalendarDraft | Сохранить авторский черновик. Возвращает 201 и id. |
| PUT /app/calendars/{calendar} | updateCalendar | Обновить свой календарь по действующим правилам даты и публикации. Возвращает 200 и id. |
| POST /app/calendars/{calendar}/publish | publishCalendar | Опубликовать заполненные отмеченные дни и закрепить адресата. |
| POST /app/received/{calendar}/{date}/open | openReceivedGift | Открыть доступную записку в подтверждённой сессии получателя. Ответ содержит text и first. |
| POST /telegram/webhook | receiveTelegramUpdate | Получить обновление из Telegram; проверяется секрет webhook. |

Для подарка себе редактор передаёт `target=self`, месяц и список дней. При `target=username` нужен также ник получателя. Если в обновлении Telegram присутствует `widget_query`, обязательны `id`, `from.id` и `data`. Другие типы обновлений могут приходить без этого объекта.

Снимок описывает состав данных и коды ответов. Нарушение правил валидации возвращает ошибки полей, конфликт публикации сообщает о занятом месяце. Ограничение частоты запросов возвращает 429 и Retry-After. Первое открытие фиксируется по нажатию на подарок. Чужой календарь и будущая дата его месяца возвращают 403. Для своего календаря неверная дата, дата за пределами месяца и прошедший или сегодняшний день без подарка дают 404. Ранее доставленный виджет получает ответ через answerWidgetQuery. Поля и примеры доступны в [снимке OpenAPI](../contracts/openapi.json).

Страницы профиля, формы Blade и интерактивные средства разработчика отделены от JSON-контрактов. Защищённая документация и схема доступны сотрудникам в Filament.
