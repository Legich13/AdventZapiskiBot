# Фабрики и демонстрационный набор

Model factories в `backend/database/factories` создают синтетические данные для изолированной PostgreSQL. Calendar связан с автором, GiftDay — с календарём и датой; сообщение и попытка отправки связаны с получателем. Для воспроизведения коллизий укажите одинаковый месяц или дату явно.

Обычный DatabaseSeeder предназначен для базовой установки. Команда `make dev-demo` добавляет демонстрационные профили и их календари в локальную базу. Затем откройте [мастерскую](../flows/publish-calendar.md) и выберите автора или получателя. Реальные тексты, токены бота и контактные данные здесь не используются.
