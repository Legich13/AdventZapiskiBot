# Проверки backend

| Набор | Наблюдаемый результат |
|---|---|
| Calendar | Публикация, смена ника, конфликт месяца, секретность будущих дней, гонка открытия. |
| Telegram | Подлинность и границы webhook, размер виджетов, доставка с 10:00, повторный update, отложенный и неизвестный ответ. |
| StudioTest | Производственные/локальные маршруты, видимость админки и переход между тестовыми профилями. Выбранная пользователем дата меняет часы подарков в пределах запроса. Сессия и ограничители частоты используют реальное время. |
| AdventArchitectureTest и TestNamingLanguageContractTest | Направление запросов, типы DTO, документация моделей и русские названия Pest. |
| DocumentationAccessTest | Защищённый доступ к /admin/docs, Scalar и JSON, проверка бизнес-операций в экспортируемой схеме. |
| ValidateFastPlanCommandTest | Корректные и повреждённые пакеты FAST_STRICT/2. |

Точечную проверку запускает `make test-suite suite=Calendar`. Меняйте значение suite для соответствующего проверяемого поведения. В RED нужна ошибка отсутствующего поведения, в GREEN — та же команда с кодом 0. Тесты конкуренции используют отдельные соединения с PostgreSQL. Нативный HTML дополнительно проверяется в официальном Telegram Widget Sandbox. Когда появится токен, контрольное уведомление проверяется на телефоне.
