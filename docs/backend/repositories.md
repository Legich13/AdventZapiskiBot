# Репозитории

| Владелец | Задача хранения | Потребитель |
|---|---|---|
| Calendar | Найти авторский черновик, получить календарь получателя, согласовать публикацию по месяцу, заблокировать день для первого открытия. | Actions календаря, сервисы редактора и экрана получателя. |
| Telegram | Сохранить и разрешить адрес сообщения, ограничить выборку доступным получателю сообщением. | Обычные сообщения бота, запросы ранее отправленных виджетов и локальный чат. |
| Telegram | `PostgresStartUpdateRepository` фиксирует вручения и выбор действия по `update_id`, резервирует свободные позиции ответа, учитывает подтверждение открытки и срок следующей попытки. | `PrepareStartUpdateAction` и `HandleTelegramUpdateAction`. |
| Telegram | Выбрать подарки к утреннему сроку, зарезервировать задание, изменить состояние после ответа Telegram. | Планировщик и обработчик очереди. |
| Admin | Постранично выбрать авторов, получателей, прогресс и состояние утренней отправки. | Read service для Filament. |
| Studio | Подготовить локальный доступ к учётной записи сотрудника. | Сценарий локальной мастерской. |

Реализации расположены в Infrastructure/Persistence владеющего модуля. Наружу передаются идентификаторы и DTO для конкретных действий. Модель строит отношения, repository загружает нужные строки, Resource отвечает за публичные поля.
