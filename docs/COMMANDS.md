# Команды

| Действие | Команда из корня |
|---|---|
| Собрать стенд, установить зависимости, мигрировать БД и запустить процессы | `make setup` |
| Запустить или остановить созданный стенд | `make up` или `make down` |
| Добавить локальные демонстрационные данные | `make dev-demo` |
| Запустить сценарии календаря | `make test-suite suite=Calendar` |
| Выполнить поведенческие проверки | `make test` |
| Запустить Laravel Boost MCP из контекста этого приложения через stdio | `make boost-mcp` |
| Проверить единый стиль и правила Rector | `make dev-lint` |
| Запустить максимальный уровень Larastan | `make dev-stan` |
| Проверить доступ к документации и актуальность OpenAPI | `make dev-docs-check` |
| Обновить контракт после изменения публичного API | `make dev-api-generate` |
| Сверить сохранённый контракт с экспортом Scramble | `make dev-api-check` |
| Проверить актуальные планы | `make dev-plan-check-all` |
| Проверить полный набор качества и готовность к сдаче | `make quality`, затем `make pre-commit` |

Контракты данных описаны в [API_CONTRACT](backend/API_CONTRACT.md). Локальный порт и входная страница указаны в [README](../README.md).
