# Accepted Decisions

- Утверждённый календарь сохраняет оформление родных виджетов; транспорт использует обычную кнопку Mini App, текст и фотографию.
- Замечания по контексту запуска и внешней транзакции проверяются через основное приложение и адаптер Telegram. Записываем отдельные исходы локального и сетевого сбоя.
- При смене пользователя проверяются права на каждом персональном запросе. Настройки session cookie соответствуют HTTPS в Telegram Web и явно задокументированному локальному входу.
- Манифест учитывает и правильные части предшествующего результата, которые этого исправления не требуют.

# Rejected Alternatives

- Переписывать старое заключение или менять утверждённый PLAN после первого ревью.
- Считать переход по GET достаточным для прочтения подарка или выдавать новое сообщение при каждом повторном старте.
