# Accepted Decisions

- Адаптировать существующий красный виджет; общие style, gift и выделенная garland поддерживают единый стиль.
- Встроенная CTA — нативная ссылка gold. Конфигурация TELEGRAM_MINI_APP_URL по умолчанию ведёт на публичную ссылку Main Mini App.
- Приветствие имеет пустую подпись и allow_queries=false. Оно не запрашивает state и не получает доступ к запискам. Совместимость соответствует уже используемым виджетам Telegram.
- Добавить календарно независимый метод существующего WidgetRenderer с RenderedWidgetDTO, без нового слоя или модели.
- Локальная карточка выводится через iframe и получает /app для текущего локального профиля; в iframe требуется выход в основную вкладку.
- Сохранить все существующие правила sendOnce, 429, вручения и авторизации.
- Внешний запуск нового кода с initData остаётся отдельным условием сдачи; публичная страница Open App его не доказывает.

# Rejected Alternatives

- Отдельный дизайн, копирование SVG/CSS, кнопка под карточкой и отдельный скрипт открытия.
- Фиктивный календарь, ослабление WidgetMessage, новая миграция, endpoint или запрос Telegram при каждом старте.
- Обход initData через прямую внешнюю ссылку на сайт; утверждение о живой проверке без её выполнения.
