# Goal

Приветствие /start использует существующий красный виджет со встроенной CTA открытия редактора.

# Scope

Приветственная карточка, общие шаблоны оформления, конфигурация ссылки, локальный предпросмотр, TDD и документация.

# Non-goals

Деплой, внешние отправки сообщений без отдельной авторизации, изменение календарных правил, БД и HTTP API.

# Operator Notes

Циклы TDD выполняются последовательно через Make в контейнере. Общие файлы пишет только /root; пакет и evidence ведёт делегат оркестратора. Сначала фиксируется baseline, затем допускаются тесты. Финальный манифест создаётся перед quality и pre-commit. Три независимых оси читают один снимок. Проверка нового виджета в живом Telegram требует опубликованного кода и отдельной авторизации внешнего действия; до этого TASK-006 остаётся открытым, план не помечается complete.
