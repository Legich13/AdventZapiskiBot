# Рабочие планы

Для нового изменения используйте FAST_STRICT/2. [Контракт V2](FAST_STRICT_V2.md) дополняет [базовый контракт V1](FAST_STRICT_V1.md). Правила архитектуры находятся в [ARCHITECTURE.md](../ARCHITECTURE.md).

1. Запишите требования и наблюдаемые критерии приёмки, три независимых анализа, исполнителей и точные пути в PLAN.json. STATUS.json содержит только фактическое состояние.
2. Зафиксируйте исходное состояние файлов. Для каждой новой возможности сохраните причину падения целевого теста и пройдите тот же тест после реализации.
3. Проведите целевые регрессии. После подготовки итогового манифеста выполните `make quality`, затем `make pre-commit`. Три независимых ревью проверяют один и тот же снимок.
4. Проверяйте пакет командой `make dev-plan-check plan=plan/advent-calendar-v2-fast-tdd phase=current`. Проверка всех планов V2 выполняется через `make dev-plan-check-all`.

[План календаря и утренних подарков](advent-calendar-v2-fast-tdd/README.md)
