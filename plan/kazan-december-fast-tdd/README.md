# Goal

Миграция публикует 31 записку, а личный /start вручает их владельцу заданного ID.

# Scope

Установочные данные production, вручение по ID, защита адресата в редакторе.

# Non-goals

Деплой на внешний сервер, отправка сообщений из миграции.

# Operator Notes

Обычный запуск миграций в production публикует подарок. Вручение фиксирует первый личный /start адресата после публикации.
