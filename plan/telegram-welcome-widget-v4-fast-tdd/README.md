# Goal

Получатель получает открытку до утреннего напоминания при переходе со старого журнала. Поддержка видит разницу между отказом Telegram и потерей подтверждения доставки.

# Scope

Локальная поставка календаря с интерфейсом исходных виджетов, защищённой запиской в Mini App и обычными сообщениями бота. Эта ревизия изменяет обработку /start, упорядочивание очереди, переход данных и эксплуатационную документацию.

# Non-goals

Внешняя выкладка и рассылка в Telegram. Сроки утренней доставки, тексты и графика приложения определены предыдущей проверенной версией.
