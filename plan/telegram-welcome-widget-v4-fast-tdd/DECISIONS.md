# Accepted Decisions

- Отдельная аддитивная миграция переводит уже созданные БД с прежней 000001. Для нового развёртывания действуют те же миграции.
- Удерживать утреннее напоминание до первой открытки в тех календарях, где прежнее вручение действительно не завершилось. При реконструкции учитывать получателя, московскую дату и признаки завершённой выдачи.
- Учитывать раздельно достоверный отказ, 429 и потерю ответа на отправку. Если Telegram мог получить фото, автоматический повтор создаёт риск дублирования.
- Сохранить интерфейс и снимки клиентских файлов из ревизии 3. Проверить общий выпуск относительно исходного Git HEAD и два новых файла в этой ревизии.

# Rejected Alternatives

- Переносить исправление в один ранее применённый migration-файл. Обычная команда migrate его пропускает.
- Откладывать определение ожидающей открытки до следующего webhook. Ранее поставленный воркер может исполниться раньше.
