# Goal

Публикация себе и поздний /start запускают сегодняшнюю карточку сразу после сохранения.

# Scope

Публикация себе, позднее вручение через /start, общая рассылка, мастерская, поведенческие тесты и профильные документы.

# Non-goals

Новые схемы БД и HTTP endpoints, изменение политики unknown/blocked, деплой и вызов настоящего Telegram.
