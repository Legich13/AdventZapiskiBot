# Accepted Decisions

Принято: одна операция dispatcher для публикации, вручения и scheduler. Резерв в транзакции, очередь afterCommit; только текущий получатель. С 10:00 вручение сравнивается с текущим GiftClock. Локальные часы передаются штатным Context очереди.
