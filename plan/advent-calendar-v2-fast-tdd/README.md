# Goal

Сохранить пользовательские сценарии календаря и реализовать их по подтверждённым границам Jobgram, с защищённым справочником процесса и проверяемым API.

# Scope

Локальные Laravel, PostgreSQL, Filament, бот и редактор календаря.

Публикация, вручение, открытие подарка и ежедневная отдельная карточка.

Проверяемый процесс FAST_STRICT/2, Pest TDD и независимые ревью.

Границы FormRequest/Policy, Action, Service, Repository, DTO, Resource; права Filament; русский Markdown и Scramble/Scalar.

# Non-goals

Доступ к реальному боту и публичная выкладка до выдачи учётных данных.

Отдельное приложение документации и клиентский стек Fumadocs.

# Operator Notes

Этот revision заменяет исходную работу после уточнения приложения правил Jobgram. Его собственный baseline совпадает с последним проверяемым деревом до реорганизации. Результаты предыдущих тестов остаются в первом пакете.
