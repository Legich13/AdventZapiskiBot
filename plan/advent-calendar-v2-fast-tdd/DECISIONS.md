# Accepted Decisions

Владелец use case получает DTO через предметный repository; SQL находится в Infrastructure/Persistence. Форма запроса, проверка права и представление отделены от перехода состояния. Markdown описывает сценарии и доступен через защищённую панель.

# Rejected Alternatives

Перенос одного валидатора планирования не контролирует структуру PHP. Вольные массивы и прямые запросы панели скрывают границы и затрудняют проверку доступа.
