# Декабрь чудес

Автор готовит календарь в Telegram Mini App, получатель открывает в нём подарки. При вручении бот отправляет в личный чат открытку с кнопкой. С 10:00 по Москве он присылает текстовое уведомление за день с подарком.

## Локальный запуск

Требуются Git, Make и Docker Compose. Выполните из корня:

```sh
make setup
make dev-demo
```

Откройте [мастерскую](http://localhost:8087/dev). Демонстрационные профили и календари создаются только в локальном окружении. Повторный запуск сохраняет существующий прогресс. Часы мастерской действуют только в текущей сессии браузера. Для другого порта задайте `ADVENT_PORT` и соответствующий `APP_URL` в `backend/.env`.

Мастерская показывает сообщения выбранного участника. Две демонстрационные декабрьские подборки уже вручены. Чтобы увидеть первую открытку, создайте в роли автора новый календарь на свободный месяц для одного из демонстрационных ников. Затем выберите этого получателя и запустите /start.

1. Выберите получателя и 7 декабря 2026 года, 09:59 МСК. Нажмите «Запустить /start». Нажмите «Мои календари» и выберите декабрь в разделе «Мне подарили».
2. В одном профиле откройте 7 декабря, во втором оставьте коробку закрытой.
3. Выберите 10:00 МСК и нажмите «Запустить утреннюю рассылку» для каждого профиля. Сравните кнопки в сообщениях и откройте подарок в Mini App. Повторный запуск за тот же день позволит проверить защиту от дублей.
4. Переключитесь на автора и откройте [редактор](http://localhost:8087/app?create=1). Можно создать календарь на другой месяц.
5. Нажмите «Открыть админку» в мастерской для локального просмотра. Для обычного входа сотрудника в [Filament](http://localhost:8087/admin) выполните команду ниже и введите пароль.

```sh
docker compose exec app php artisan advent:staff admin@example.test
```

`make up` запускает существующую установку, `make down` останавливает контейнеры. Данные находятся в отдельном именованном томе PostgreSQL.

## Подключение к Telegram

Задайте публичный HTTPS-адрес приложения в `APP_URL`, установите `APP_ENV=production`, `APP_DEBUG=false`, ключ приложения, параметры PostgreSQL, `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`. Установите файлы приложения с обложкой, выполните штатные миграции и запустите приложение, планировщик и работников очереди.

В BotFather укажите адрес главной Mini App с путём `/app`. Для `setWebhook` используйте путь `/telegram/webhook`, тот же секрет и `allowed_updates=["message"]`. Кнопки бота открывают главную, редактор, месяц или конкретный день в Mini App. Первое вручение можно проверить, опубликовав календарь для тестового адресата и открыв личный чат с ботом.

Обычный подарок при /start получает владелец указанного ника. После этого доступ привязан к ID Telegram. День доступен с 00:00 МСК. Рассылка начинается с 10:00 МСК. Если человек приходит после 10:00, бот сначала отправляет открытку. После подтверждения доставки он присылает ссылку на сегодняшний подарок. Для календаря себе рассылка начинается сразу после публикации. Доставка учитывает только текущий московский день. Статус «Результат неизвестен» означает, что подтверждение Telegram не дошло и повтор может создать второе сообщение. Первое открытие записки учитывается отдельно.

При запуске штатных миграций с `APP_ENV=production` приложение публикует персональный календарь на 1–31 декабря 2026 года. Оба участника заданы по Telegram ID. Получатель увидит календарь при первом личном /start после публикации. До этого утренние карточки не отправляются. Если декабрь уже занят другим опубликованным подарком для этого получателя, миграция завершается ошибкой и сохраняет прежние данные.

## Справочник и API

После входа сотрудника Filament показывает [справочник проекта](http://localhost:8087/admin/docs). В нём собраны правила разработки и бизнес-процессы календаря. Детали операций, формы запросов и ответы доступны в [Scalar](http://localhost:8087/scalar). Те же материалы можно прочитать в репозитории. [Профиль backend](docs/backend/README.md) · [Снимок OpenAPI](docs/contracts/openapi.json)

После изменения публичного API выполните `make dev-api-generate`. Команда `make dev-api-check` сверяет сохранённый JSON с новым экспортом. Проверки доступа к справочнику и актуальности схемы объединены в `make dev-docs-check`. [Справочник команд](docs/COMMANDS.md)

## Хранение данных

| Таблица | Назначение |
|---|---|
| `telegram_users` | Постоянный числовой ID Telegram и последний подтверждённый ник. |
| `calendars` | Автор, адресат, месяц, публикация и вручение. До вручения уникальность обеспечивается по нику и месяцу, после вручения — по ID и месяцу. |
| `gift_days` | Выбранная дата, личный текст и момент первого открытия. Все входы обращаются к одной записи под блокировкой PostgreSQL. |
| `widget_messages` | Получатель, текст сообщения и его кнопка. Для открытки хранится путь обложки, для утреннего сообщения — календарь и дата. Старый HTML остаётся у прежних локальных виджетов. |
| `morning_deliveries` | Одна строка на получателя и дату. Хранит статус, попытку отправки и связь с исходящим сообщением. |
| `users` и таблицы Spatie | Учётные записи сотрудников и их права Filament. |

Даты подарков хранятся как календарные даты, моменты событий — в UTC. Для допуска к открытию и утренней доставке используется Europe/Moscow.
