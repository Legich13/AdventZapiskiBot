# Декабрь чудес

Персональный календарь подарков в личном чате Telegram. Автор заполняет выбранные дни в Mini App, получатель открывает записки в виджете. С 10:00 по Москве бот отправляет отдельную карточку за сегодня, даже если подарок уже открыли.

## Локальный запуск

Требуются Git, Make и Docker Compose. Выполните из корня:

```sh
make setup
make dev-demo
```

Откройте [мастерскую](http://localhost:8087/dev). Демонстрационные профили и календари создаются только в локальном окружении. Повторный запуск сохраняет существующий прогресс. Часы мастерской действуют только в текущей сессии браузера. Для другого порта задайте `ADVENT_PORT` и соответствующий `APP_URL` в `backend/.env`.

При выбранном профиле мастерская показывает красное приветствие бота с кнопкой «Создать календарь». Карточка использует тот же шаблон, что и Telegram; локальная кнопка открывает редактор выбранного профиля.

1. Выберите получателя и 7 декабря 2026 года, 09:59 МСК. Нажмите «Запустить /start». Календарь появится в локальном чате.
2. В одном профиле откройте 7 декабря, во втором оставьте коробку закрытой.
3. Выберите 10:00 МСК и нажмите «Запустить утреннюю рассылку» для каждого профиля. Сравните карточки. Повторный запуск за тот же день позволит проверить защиту от дублей.
4. Переключитесь на автора и откройте [редактор](http://localhost:8087/app). Можно создать календарь на другой месяц.
5. Нажмите «Открыть админку» в мастерской для локального просмотра. Для обычного входа сотрудника в [Filament](http://localhost:8087/admin) выполните команду ниже и введите пароль.

```sh
docker compose exec app php artisan advent:staff admin@example.test
```

`make up` запускает существующую установку, `make down` останавливает контейнеры. Данные находятся в отдельном именованном томе PostgreSQL.

## Подключение к Telegram

Разверните приложение по HTTPS, установите `APP_ENV=production`, `APP_DEBUG=false`, постоянный ключ приложения, URL, учётные данные PostgreSQL, `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`. Настройте в BotFather адрес Mini App на `/app`. Для webhook задайте тот же секрет в `setWebhook`, URL `/telegram/webhook` и типы обновлений `message`, `widget_query`. Запустите процессы приложения, планировщика и работников очереди. Локальные значения окружения и учётных данных предназначены для Docker-стенда.

Кнопка внутри приветственного виджета использует `TELEGRAM_MINI_APP_URL` (по умолчанию `https://t.me/AdventZapiskiBot?startapp`). Для этого адреса включите главную Mini App бота в BotFather и укажите `https://prokitap.ddns.net/app`. После выкладки проверьте в Telegram, что кнопка открывает редактор с авторизацией; переход на обычный адрес сайта эту проверку не заменяет.

Обычный подарок при /start получает владелец указанного ника. После этого доступ привязан к ID Telegram. День доступен с 00:00 МСК. Рассылка начинается с 10:00 МСК. При публикации себе или вручении через /start после этого времени сегодняшняя карточка сразу ставится в очередь, без ожидания планировщика. Прошлые дни не досылаются. Статус «Результат неизвестен» означает, что подтверждение Telegram не дошло и повтор может создать второе сообщение. Успешная отправка не означает прочтение подарка.

При запуске штатных миграций с `APP_ENV=production` приложение публикует персональный календарь на 1–31 декабря 2026 года. Оба участника заданы по Telegram ID. Получатель увидит календарь при первом личном /start после публикации. До этого утренние карточки не отправляются. Если декабрь уже занят другим опубликованным подарком для этого получателя, миграция завершается ошибкой и сохраняет прежние данные.

## Справочник и API

После входа сотрудника Filament показывает [справочник проекта](http://localhost:8087/admin/docs). В нём собраны правила разработки и бизнес-процессы календаря. Детали операций, формы запросов и ответы доступны в [Scalar](http://localhost:8087/scalar). Те же материалы можно прочитать в репозитории. [Профиль backend](docs/backend/README.md) · [Снимок OpenAPI](docs/contracts/openapi.json)

После изменения публичного API выполните `make dev-api-generate`. Команда `make dev-api-check` сверяет сохранённый JSON с новым экспортом. Проверки доступа к справочнику и актуальности схемы объединены в `make dev-docs-check`. [Справочник команд](docs/COMMANDS.md)

## Хранение данных

| Таблица | Назначение |
|---|---|
| `telegram_users` | Постоянный числовой ID Telegram и последний подтверждённый ник. |
| `calendars` | Автор, адресат, месяц, публикация и вручение. До вручения уникальность обеспечивается по нику и месяцу, после вручения — по ID и месяцу. |
| `gift_days` | Выбранная дата, личный текст и момент первого открытия. Обе карточки обращаются к одной записи под блокировкой PostgreSQL. |
| `widget_messages` | Связь сообщения Telegram с календарём, получателем и при необходимости конкретной датой. В локальном окружении дополнительно хранится отправленный HTML. |
| `morning_deliveries` | Одна строка на получателя и дату. Хранит статус, попытку отправки и связь с исходящим сообщением. |
| `users` и таблицы Spatie | Учётные записи сотрудников и их права Filament. |

Даты подарков хранятся как календарные даты, моменты событий — в UTC. Для допуска к открытию и утренней доставке используется Europe/Moscow.
